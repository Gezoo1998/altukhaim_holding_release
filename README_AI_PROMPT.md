# دليل إنشاء موقع شركة عد العقارية للتسويق العقاري

## نظرة عامة على المشروع
إنشاء صفحة هبوط بتقنية Flutter للويب لـ "شركة عد العقارية للتسويق العقاري" بتصميم ووظائف مشابهة لمشروع الطخيم القابضة الحالي.

## متطلبات التصميم

### الخلفية والتصميم البصري
- استخدام خلفية بيضاء مشابهة مع عناصر تدرج خفيفة مثل المشروع الحالي
- تطبيق نفس تخطيط قسم البطل مع الأشكال الزخرفية
- الحفاظ على الجمالية النظيفة والحديثة مع الألوان السعودية (الأخضر والذهبي)
- استخدام نفس أنماط الطباعة والمسافات
- تضمين عناصر زخرفية هندسية للاهتمام البصري

### الميزات الأساسية المطلوبة

#### 1. قسم الرأس
- منطقة شعار الشركة
- قائمة التنقل (إذا لزم الأمر)
- تصميم متجاوب للجوال وسطح المكتب
- **بدون تبديل لغة - الموقع بالكامل باللغة العربية السعودية فقط**

#### 2. قسم البطل
- اسم الشركة: "شركة عد العقارية للتسويق العقاري"
- وصف موجز لخدمات التسويق العقاري
- زران واتساب بارزان لأغراض مختلفة:
  - الزر الأول: "تواصل للاستفسار"
  - الزر الثاني: "طلب خدمة عقارية"

#### 3. تكامل الواتساب
- **أرقام هواتف ثابتة** (بدون تحويل ديناميكي)
- تطبيق آلية الصفحة الوسيطة مثل المشروع الحالي
- عند النقر على زر الواتساب:
  1. الانتقال إلى صفحة التحميل الوسيطة
  2. عرض رسوم متحركة للتحميل مع الأيقونات
  3. إعادة التوجيه إلى الواتساب مع رسالة معبأة مسبقاً
  4. تحميل سريع وانتقالات سلسة

#### 4. متطلبات الأداء
- تحميل سريع للأيقونات والأصول
- صور محسنة (استخدام SVG حيثما أمكن)
- رسوم متحركة وانتقالات سلسة
- تصميم متجاوب لجميع أحجام الشاشات
- إعادة توجيه سريعة للواتساب

- تطبيق نفس الأشكال الزخرفية المتدرجة
- الحفاظ على طباعة متسقة (خطوط عربية)
- اتباع نفس نقاط الاستجابة
- استخدام أنماط أزرار وتأثيرات تمرير مشابهة

### الأصول المطلوبة

- أيقونة الواتساب (SVG)
- أيقونات متعلقة بالعقارات (SVG)
- أصول الرسوم المتحركة للتحميل

## الميزات المحددة للتكرار

### من المشروع الحالي:
1. **نظام الخلفية المتدرجة**: قاعدة بيضاء مع أشكال متدرجة خضراء خفيفة
2. **رأس متجاوب**: نفس هيكل التنقل
3. **تخطيط قسم البطل**: نفس الموضع والتسلسل الهرمي البصري
4. **تكامل الواتساب**: نفس آلية الصفحة الوسيطة بالضبط
5. **رسوم متحركة للتحميل**: نفس نظام تحميل الأيقونات للأداء السريع
6. **الاستجابة للجوال**: نفس نقاط الكسر والتكيفات المحمولة

### ملاحظات التطبيق الثابت:
- بدون تبديل لغة ديناميكي (عناصر واجهة المستخدم فقط)
- أرقام هواتف ثابتة في الكود
- رسائل واتساب محددة مسبقاً
- محتوى ثابت (لا حاجة لتكامل نظام إدارة المحتوى)

## المخرجات المتوقعة
1. مشروع Flutter للويب كامل
2. تصميم متجاوب يعمل على جميع الأجهزة
3. أداء تحميل سريع
4. تكامل واتساب يعمل مع صفحات وسيطة
5. هيكل كود نظيف وقابل للصيانة
6. تصميم بصري مشابه للمشروع المرجعي

## أهداف الأداء
- تحميل الصفحة الأولي: أقل من 3 ثوانٍ
- إعادة توجيه الواتساب: أقل من ثانية واحدة
- رسوم متحركة سلسة بمعدل 60 إطار في الثانية
- تحميل أصول محسن

## متطلبات الاختبار
- اختبار روابط الواتساب على الجوال وسطح المكتب
- التحقق من التصميم المتجاوب على أحجام شاشات مختلفة
- فحص أداء التحميل
- التحقق من عرض النص العربي
- اختبار انتقالات الصفحة الوسيطة

هذا الدليل يجب أن يوجه وكيل الذكاء الاصطناعي لإنشاء صفحة هبوط عقارية مهنية بنفس الجودة والوظائف الخاصة بمشروع الطخيم القابضة الحالي، مخصصة خصيصاً لـ "شركة عد العقارية للتسويق العقاري" **بالكامل باللغة العربية السعودية**.
